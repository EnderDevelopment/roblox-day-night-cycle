# Roblox Day and Night Cycle Script

This project contains a script for a day and night cycle in Roblox. It allows you to create a dynamic environment with changing lighting conditions to simulate day and night.

## Installation

1. Open Roblox Studio.
2. Create a new script in the ServerScriptService.
3. Copy the content of `DayNightCycleScript.server.lua` into the new script.

## Usage

1. Adjust the day and night lengths by changing the `DAY_LENGTH` and `NIGHT_LENGTH` variables in the script.
2. Run the game. The script will automatically start the day and night cycle when the game starts. The cycle will change the lighting conditions to simulate day and night.
